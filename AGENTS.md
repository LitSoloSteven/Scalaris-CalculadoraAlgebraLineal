# Scalaris

Estas instrucciones se comparten entre Codex y Google Antigravity. Las reglas del proyecto están en `docs/__SCALARIS_REGLAS_DEL_AGENTE.txt`.

- Lee las secciones 0 y 1 para el alcance, 16.1–16.2 para elegir modelo y organizar el trabajo, 6 y 10 para revisar y verificar, y 15 al hacer commits. Para cambios de código consulta 2–5. Si tocas interfaz, usa 7–9 según el cambio. En tareas por fases aplica 11–12 y abre solo la fase autorizada del plan.
- Para explorar estructura, usa la skill **Codebase Memory** con su MCP e índice. **Graphify** es el respaldo sobre el índice existente. Aplica 16.3 y usa `rg` para texto y configuración. Al continuar una tarea, parte del avance y del estado real de Git.
- Usa un agente principal por tarea. Codex y Antigravity comparten el mismo alcance. El lanzador de 16.2 cambia al otro cliente solo con un error explícito de cuota. Usa 16.4 y 16.5 para limitar el consumo.
- Consulta `ponytail` para cambios acotados. Para `ub-mode`, Superpowers y RTK, aplica las condiciones de uso de 16.5.
- Postman CLI está disponible en este equipo para trabajo de API.

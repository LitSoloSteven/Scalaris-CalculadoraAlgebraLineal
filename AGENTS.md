# Scalaris

Estas instrucciones se comparten entre Codex, Google Antigravity y OpenCode. Las reglas del proyecto están en `docs/__SCALARIS_REGLAS_DEL_AGENTE.txt`.

- Lee las secciones 0 y 1 para el alcance, 16.1–16.2 para elegir modelo y organizar el trabajo, 6 y 10 para revisar y verificar, y 15 al hacer commits. Para cambios de código consulta 2–5. Si tocas interfaz, usa 7–9 según el cambio. En tareas por fases aplica 11–12 y abre solo la fase autorizada del plan.
- Para explorar estructura, usa la skill **Codebase Memory** con su MCP e índice si están disponibles. Con **Graphify**, consulta el índice existente como alternativa y aplica la sección 16.3 para elegir herramienta, limitar resultados y comprobar frescura. Para texto y configuración usa `rg` con rutas acotadas.
- En fases de código, Codex implementa y prueba, OpenCode Desktop revisa el diff y Antigravity verifica la experiencia en ejecución. Usa los relevos de 16.2, el punto de control de cupo de 16.4 y las skills activas de 16.5.
- Postman CLI está disponible en este equipo para trabajo de API.
